# Security Policy

HackersGhost AI is security-focused software. Please report suspected vulnerabilities privately rather than opening a public issue when a report could expose users, credentials, update-signing material, or another security weakness.

## Reporting a vulnerability

Email **info@hackersghost.com** with:

- the affected version;
- the component or file involved;
- clear reproduction steps;
- the security impact you expect;
- logs or proof-of-concept material with secrets removed where possible.

Do not include API keys, passwords, private keys, access tokens, or unrelated personal data in a report.

## Scope

The maintainers are especially interested in reports involving credential handling, update verification, path traversal or unsafe file handling, desktop-launcher behavior, unintended command execution, request-data leakage, and bypasses of the application's advisory-only design.

The public preview is provided for testing and development. Security fixes may be released without maintaining long-term support for older preview versions.
